# C# to Java map for Intern B

| .NET | Java / Spring |
| --- | --- |
| Properties | Fields with getters/setters, or records |
| LINQ | Streams |
| NuGet, dotnet CLI | Maven, mvnw |
| ASP.NET Core DI | Spring IoC container |
| [ApiController] controllers | @RestController |
| appsettings.json | application.yml and profiles |
| Entity Framework Core | Spring Data JPA / Hibernate |
| EF Core migrations | Flyway |
| JWT bearer auth, ASP.NET Identity | Spring Security, OAuth2 Resource Server |
| xUnit, Moq | JUnit 5, Mockito |
| async/await, Task | CompletableFuture, virtual threads |
| No equivalent | Checked exceptions, generic type erasure, no operator overloading |
