# Week 2, Session 2B: Classes and Objects

Slides: `../Session04_Classes_and_Objects.pptx`

## Run a file

```bash
cd files/session-04
java demos/ClassBasics.java
```

Each demo file has its main class first, then the helper classes. `java File.java` runs the first class.

## Demos

| File | Topic |
| --- | --- |
| `ClassBasics.java` | Class, object, fields, constructor, methods |
| `ThisAndStatic.java` | `this`, instance vs `static` members |
| `StackHeap.java` | References, aliasing, `==` vs `equals`, `NullPointerException` |
| `Encapsulation.java` | `private` fields, getters, validating setters |
| `ObjectMethods.java` | `toString`, `equals`, `hashCode` |
| `ArrayOfObjects.java` | Array of objects, null slots |

To see `StackHeap.java` run line by line, open `visuals/StackHeap.html` in a browser. Press Next or the right arrow key to step through, or Play to run it on its own.
